# Bahasa Cinta Kita ♡

Landing page statis bertema love language dengan pre-test dan post-test interaktif.

## Cara menjalankan
Buka `index.html` di browser. Tidak membutuhkan framework, server, atau API.

## Publikasikan ke GitHub Pages
1. Buat repository baru di GitHub, misalnya `bahasa-cinta-kita`.
2. Upload `index.html` dan `README.md` ke root repository.
3. Buka **Settings → Pages**.
4. Pada **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu beberapa menit. GitHub akan menampilkan URL website di bagian Pages.

## Kustomisasi
- Edit kalimat romantis di bagian `id="surat"` pada `index.html`.
- Ganti judul `Bahasa Cinta Kita ♡` dan teks hero sesuai nama panggilan kalian.
- Semua jawaban diproses di browser; hasil tidak dikirim atau disimpan ke server.
